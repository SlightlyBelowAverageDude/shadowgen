ShadowGen filter variants

3 ways to score a model with the same 1,000 shadow traces, compared with the true value and with training fitness. The true value is the share of real future cases with an unseen variant that the model accepts.

1. What each variant does

All 3 variants draw the same shadow traces from the training log. They differ only in which of these traces are replayed on the model.

5 real shadow traces from L1 (Sepsis) and what each variant does with them

The highlighted activity is the one the rule is about.

2. What the filters remove

A filter is useful when the traces it removes are invalid. It is harmful when it removes valid behavior. Both are measured.
